Path 1

Install the desktop wallet

Download coming at launch

The Tracercoin wallet is a standalone desktop app you run on your own computer. It holds your keys, syncs the chain, and lets you send and receive TFX.

  1. 1

    Download

    Grab the Tracercoin Core wallet for your operating system from the downloads page. Verify the checksum shown next to the file before you run it.

  2. 2

    Install & sync

    Open the app and let it connect to the network. The first launch downloads and verifies the blockchain — this can take a while. You'll see progress at the bottom of the window.

  3. 3

    Encrypt & back up

    Set a strong wallet passphrase, then back up your wallet file. Write down your recovery details and keep them offline — whoever holds the keys holds the coins.

  4. 4

    Send & receive

    Use the Receive tab to generate a tfx… address, and the Send tab to pay one. That's it — you're on the network.

Path 2

Start mining on the pool

Have Scrypt hardware — an Antminer L7 / L3+ or a GPU rig? Point it at the community pool, contribute hash power, and earn newly minted TFX for the blocks your hardware helps find.

  1. 1

    Create a worker

    Sign in to the miner portal and add a worker. You'll get a worker.name and password your rig will log in with.

  2. 2

    Point your rig

    In your miner's settings, set the Scrypt stratum URL to pool.tracercoin.org:3333 and enter your worker credentials.

  3. 3

    Watch it work

    The portal dashboard shows your live hashrate, shares, blocks found, and payout history — round by round.

Path 3

Run your own full node

For advanced users

Want to help decentralize the network? Run a full node on your own server. It keeps a complete copy of the chain, relays transactions, and strengthens the network for everyone.

  1. 1

    Provision a server

    Any small Linux server works. Install the build tools, then build or install the tracercoind daemon.

  2. 2

    Configure & connect

    Create a tracercoin.conf, add the seed node, and open the P2P port so peers can reach you.

  3. 3

    Sync & verify

    Start the daemon and let it sync from genesis. Once your block height matches the network, your node is live and helping secure the chain.

Step-by-step README: the full node & replication guide — provisioning, building the daemon, config, and verifying consensus — is published with the source. Ask in the community if you'd like a hand.

Help & support

Stuck on a step? Start with the video for that path, then check the answers below.

Where do I download the wallet?

The desktop wallet is in final testing. The download will be posted on this site the moment it's ready — join the waitlist and we'll notify you. Every release will list a checksum so you can verify the file before running it.

Do I need special hardware to mine?

Tracercoin uses Scrypt proof-of-work, so you can mine with standard Scrypt ASICs like the Antminer L7 or L3+, or with a GPU. See the full mining guide for setup details.

Is my wallet backup important?

Yes — critically. Your wallet holds your keys. If you lose your wallet file and passphrase, no one can recover your coins for you. Back up your wallet and store the recovery details offline.
